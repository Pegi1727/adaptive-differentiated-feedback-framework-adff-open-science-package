# ADFF: Adaptive Differentiated Feedback Framework

This repository contains the manuscript, figures, data package, and supplementary files for:

**Adaptive Differentiated Feedback Framework (ADFF): Enhancing EFL Writing Development through Proficiency-Sensitive Generative AI Feedback**

## Key Results

| Outcome | Result |
|---|---|
| Main effect of feedback condition | Significant |
| Interaction: feedback method x proficiency level | F(2,117)=18.42, p<.001, eta_p^2=.18 |
| Post-test improvement pattern | Largest gains in A2 learners |
| Overall conclusion | ADFF outperformed generic AI feedback in supporting writing development |

## Overview

ADFF is a proficiency-sensitive generative AI feedback model designed to align feedback complexity with EFL learners' language proficiency levels (A2, B1, C1). The study uses a quasi-experimental mixed-methods design to compare adaptive feedback with conventional AI-generated feedback.
